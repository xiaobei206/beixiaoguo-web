# 贝小果（beixiaoguo-web）

面向家庭局域网的短剧 Web 客户端。后端使用 Go，前端使用原生 TypeScript/JavaScript、HTML 与 CSS；构建后由一个 Go 可执行文件提供网页和 API。

> 当前版本：**0.1.9**
>
> 本项目是非官方个人项目，与红果短剧及其运营方无关联。请遵守内容平台的服务条款与适用法律，仅访问有权访问的内容。

## 0.1.9

- N1 / iStoreOS 改用 OpenWrt 原生 `procd` 服务：程序持久化安装在 `/usr/bin/beixiaoguo`，启用开机自启。
- 主服务异常退出后由 procd 无限重试拉起；独立健康检查每 15 秒检查本机 health，连续 3 次失败时请求 procd 重启应用实例。
- 运行日志交给 OpenWrt 的 RAM 日志缓冲，使用 `logread | grep -i beixiaoguo` 查询；运行状态、缓存和媒体会话仍在 RAM。
- 更新脚本先校验二进制 SHA-256 与服务脚本语法，再替换程序、启用服务并做健康检查；失败时尝试恢复旧程序。
- 一次性写入持久化二进制和服务定义是开机自启的必要条件；日常运行不持续写入 TF 卡。

## 0.1.6

- 随机选片场景优先准备足量候选：发现、搜索、排行榜和新剧列表逐页预载，目标至少 100 部；每页返回即追加展示，不等待整批结束。

- 页面缓存恢复后如果不足 100 部且仍有游标，会继续补齐；保留筛选 TAG、游标、去重和手动加载按钮。
- 本版重点改善随机选片前的候选池准备速度；上游接口耗时仍会影响 100 部候选池的最终准备时间。

- 自动续载失败时停止自动重试，避免网络异常时连续请求；新剧日期翻页会继续使用同一天的游标。
- CI 增加搜索筛选映射测试。两页预载和自动翻页的真实 N1 / 手机浏览器体验仍需实机确认。

## 0.1.4

- 修复红果 CDN 的 HEIC 封面在 Chromium / WebView 中无法显示的问题：仅对已知图片 CDN 的 `/novel-pic/` HEIC 对象尝试官方 JPEG 变体；校验 JPEG 文件头后缓存并返回 `image/jpeg`。
- JPEG 变体失效、返回错误格式或请求失败时，记录不含签名 URL 的诊断并回退原始图片地址；普通图片不改变请求路径。
- 不增加图片解码依赖、不写入 N1 TF 卡，转换后的 JPEG 仍使用现有 RAM 缓存。
- 自动化测试覆盖 CDN 地址识别、查询参数移除、JPEG 响应校验及失败回退；N1 实机显示仍待验收。

## 0.1.3

- 修复 N1 一键更新脚本错误地校验另一种 CPU 架构文件的问题；现在只校验本机下载的 ARM64 或 AMD64 文件，校验失败会在停止旧进程前终止。

- 图片通过 N1 同源代理访问，支持安全跟随有限 CDN 重定向，并使用 RAM 缓存，避免手机直接访问第三方图片 CDN。
- 页面切换保留已访问列表、分页游标和滚动位置；N1 目录 API 使用有界 RAM 缓存。
- 播放器支持 0.5×–3× 倍速、上下滑动切换集数、上一集/下一集和自动连播。
- 增加 N1 mDNS 发现 hongguoTV，并通过现有 protocol v1 将当前剧集、集数和播放位置交接到电视。
- mDNS 发现会分阶段查询 PTR、SRV、TXT、A/AAAA 记录，不再依赖电视一次性返回完整记录集；图片代理允许最多 5 次经过校验的重定向。
- 这些功能以 CI 自动化测试与 ARM64/AMD64 编译验证；真实 N1、手机 CDN 图片及电视端接力仍需实机验收。

## 目标与架构

- 为手机、平板和电脑提供真正响应式的浏览体验。
- 复用 [openhongguo Go SDK](https://github.com/xiaobei206/openhongguo) 的目录、搜索、榜单、剧集和播放模型接口。
- 面向 N1 / iStoreOS / ARM64，以单一静态 Go 二进制部署。
- 静态网页通过 `embed.FS` 嵌入程序，不需要 Node.js 运行时或数据库。
- SDK 匿名设备档案、目录缓存、封面缓存、媒体会话均在进程内存；默认不写 TF 卡。
- 播放链路已接入 CENC AES-CTR 按需解密与 HTTP Range 转发，不做整片下载、不做 N1 视频转码。
- 电视接力由 N1 服务端处理 mDNS 和 TCP，浏览器只访问同源 HTTP API。

## N1 / iStoreOS 安装与更新

推荐使用仓库内的一键更新脚本。脚本从 GitHub Releases 下载与设备架构匹配的正式版并校验 SHA-256，将程序安装到持久化的 `/usr/bin/beixiaoguo`，再注册 `/etc/init.d/beixiaoguo` 开机服务和健康检查守护。只有安装/升级时才写入持久化存储；运行日志由 OpenWrt RAM 日志系统保存，不持续写 TF 卡：

```sh
wget -qO /tmp/beixiaoguo-install.sh https://raw.githubusercontent.com/xiaobei206/beixiaoguo-web/main/scripts/install-n1.sh && sh /tmp/beixiaoguo-install.sh
```

默认监听 `0.0.0.0:8780`，家庭网络访问 `http://N1_IP:8780`；Tailscale 设备可尝试 N1 自身的 Tailscale IP。管理命令：`/etc/init.d/beixiaoguo status|start|stop|restart`；查询开机自启：`/etc/init.d/beixiaoguo enabled`；查看日志：`logread | grep -i beixiaoguo`。脚本会在当前 SSH shell 结束后返回提示符，不会打开新窗口。

## 本地开发

需要 Go 1.22 或更新版本：

```sh
go run ./cmd/beixiaoguo
make test
make build-arm64
```

默认本机打开 `http://127.0.0.1:8780`。构建版本从仓库根目录的 `VERSION` 读取，并通过 linker flags 注入二进制。

## API

播放 API：`GET /api/v1/play/{episodeID}?quality=720p` 返回同源媒体地址；浏览器随后使用 `GET /api/v1/media/{token}` 和标准 `Range` 请求播放。令牌、上游 URL 与 CENC 密钥仅保存在服务端内存。

封面代理：目录 API 的 `cover_url` / `avatar_url` 等字段会被改写为 `/api/v1/images/{token}`。N1 最多缓存约 96 MiB 图片到 RAM，缓存 12 小时；浏览器获得 12 小时 HTTP 缓存。目录 API 响应也在 N1 内按操作类型做有限 TTL 缓存。
